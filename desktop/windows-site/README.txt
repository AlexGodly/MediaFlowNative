MediaFlow by Alex Godly — Windows Desktop

Open "MediaFlow by Alex Godly.exe" to launch the application.
This uses the official MediaFlow website at https://alexgodly.github.io/MediaFlow/ inside Microsoft Edge WebView2.
It uses the same website interface, Supabase account, website features and responsive desktop layout.

Requirements: Windows 10/11 x64 and Microsoft Edge WebView2 Runtime installed.
Windows 11 normally includes the runtime. To install it manually:
https://developer.microsoft.com/en-us/microsoft-edge/webview2/

Your account session is kept in %LOCALAPPDATA%\MediaFlow by Alex Godly\WebView2.
It may need you to sign in the first time.

Keep your website backups before deleting older locally-saved app data. The app does not
install a second MediaFlow backend or independently recreate web features.
Downloads use the Windows WebView2 browser engine.
